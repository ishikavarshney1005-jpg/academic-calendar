# Academic Planner V2

This version keeps the original planner structure and adds an advanced attendance tracker.

## Attendance features

* Minimum attendance target selector
* Overall attendance percentage
* Present, absent, and unmarked counts
* Course wise attendance
* Risk filter
* Classes needed to reach the target
* Approximate classes that can be missed while staying above target
* Projection if all unmarked sessions are treated as present
* One click mark all unmarked past sessions as present
* Existing session level Present and Absent buttons
* Attendance target saved in browser storage
* Existing attendance sync remains intact

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open Settings > Pages.
4. Select Deploy from a branch.
5. Select the main branch and root folder.
6. Save.
7. GitHub will provide the public Pages address.

The original app already contains its own data and sync logic, so this V2 is intentionally kept as a single HTML file.
